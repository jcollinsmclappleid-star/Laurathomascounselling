# Core design direction
Forest: #173e35. Cream: #f4efe4. Sage: #dce3d3. Terracotta: #9b4935. Clay: #e6cbbb.
Editorial serif: Cormorant Garamond; body/navigation: Inter. Font files retain their supplied filenames; the .woff2 filenames contain TrueType font data, so follow the supplied reference @font-face format or convert/rename correctly before production. Licences included.
Use a fluid type scale: restrained headings, readable body text, generous space and visible service navigation. Preserve the rich photographic homepage and mobile two-choice entrance. Related local content is the parent journey's substance.
