## Interactive demonstration
Download the HTML and open it in a modern desktop browser. It contains its own images, fonts and scripts. Use the review navigation to compare Editorial and Split-screen, then choose either world in the homepage. Explore the gateway, service, article and books designs. Both individual book concepts are available from their cards.

The Motion checkbox controls the enhanced journey. The operating system's reduced-motion setting takes precedence. Escape cancels an active transition. The full Parentology World and retailer links are ordinary external links; the prototype does not collect personal information, send enquiries or make bookings.

The HTML is a presentation prototype with local hash routes, not a complete Next.js build. It deliberately has a larger embedded asset payload for offline portability. The production build requires approved copy/assets, actual URLs, CMS migration, integration and performance work as specified.
