# Visual direction 02: response to presentation feedback

The client presentation has been rewritten and redesigned as a 18-page deck. It leads with the commercial opportunity, makes the relationship to Google and AI search clearer, and uses fewer explanatory slide panels. A darker photographic homepage, a stronger terracotta Parentology arrival and a more prominent book showcase explore a bolder creative direction.

Home.png, Parentology.png, Books.png and Mobile_Home.png are the new visual studies. Their self-contained HTML source is supplied for inspection. These are static art-direction studies, not a complete second application or a rebuilt production website.

The original mockup pack remains as the more extensive page-architecture reference. The earlier interactive HTML and motion film remain as demonstrations of the journey and transition pattern. Their first-direction visual styling has not been fully replaced. Cursor should combine the approved new art direction with the existing architecture and motion specification after review, rather than treating the older cream homepage as the final approved look.

The new views use the same real Laura portrait, verified cover artwork and existing Parentology logo, alongside the previously labelled generated supporting photographs. No professional claims, chapter headings, testimonials or performance forecasts have been invented.

The subsequent mobile update is documented in BRANDING_AND_MOBILE_MVP_NOTES.md. The actual counselling logo is now in the site header; both businesses’ logos appear in the presentation.
